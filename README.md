# Volt Battery

[English](README.en.md)

Компактное приложение для macOS, написанное на Electron и JavaScript, без Swift и Python. Показывает заряд Mac, напряжение, остаточную, полную и проектную ёмкость, оценку состояния от macOS, число циклов и подключение зарядного устройства. Показания Mac обновляются каждые 2,5 секунды, iPhone/iPad — каждые 10 секунд.

Для Mac приложение отдельно показывает максимальную ёмкость **по macOS** и отношение сырых значений `полная ёмкость / проектная ёмкость`. Эти проценты могут различаться: второй показатель является простым расчётом по текущим данным контроллера батареи и не равен оценке состояния в macOS.

При первом открытии приложение предлагает выбрать русский или английский язык. Выбор сохраняется; переключатель RU/EN находится в правом верхнем углу окна.

## Запуск

Скачайте DMG из [релизов](https://github.com/grosa787/volt-battery/releases) и перетащите приложение в Applications. Для чтения iPhone/iPad на Mac нужны утилиты `libimobiledevice`. Для запуска из исходников: `npm install`, затем `npm start`. Для сборки: `CSC_IDENTITY_AUTO_DISCOVERY=false npm run dist`.

Приложение не подписано сертификатом Apple. При первом открытии macOS может попросить подтвердить запуск через **Системные настройки → Конфиденциальность и безопасность**.

## iPhone и iPad

1. Подключите устройство кабелем, разблокируйте его и нажмите **Доверять этому компьютеру**.
2. Для работы по Wi‑Fi откройте устройство в Finder и включите **«Показывать этот iPhone/iPad при подключении к Wi‑Fi»**. Mac и устройство должны быть в одной сети.
3. При необходимости установите утилиты: `brew install libimobiledevice`.

Приложение ищет сопряжённые устройства автоматически. USB и Wi‑Fi подключения одного устройства объединяются по идентификатору, с приоритетом USB. Когда устройство спит или вышло из сети, последние полученные значения остаются на экране до 5 минут с явной пометкой времени; затем исчезают. iOS предоставляет часть сведений через неофициальный диагностический протокол, поэтому отдельные показатели могут отсутствовать или отличаться между моделями и версиями iOS. Значение `—` означает, что поле не было получено; приложение не подставляет вымышленные данные. «Состояние» в процентах вычисляется как полная ёмкость / проектная ёмкость, когда обе доступны.

## Проверка

`npm test` запускает тесты преобразования, защиты от неверно размеченной ёмкости iOS и сохранения последних данных при кратком обрыве связи. `node -e "require('./electron/telemetry').snapshot('all').then(console.log)"` читает текущие системные показания.

Источники: [Apple о синхронизации по Wi‑Fi](https://support.apple.com/en-lk/guide/mac-help/mchlada1d602/mac), [libimobiledevice](https://github.com/libimobiledevice/libimobiledevice), [команды диагностики](https://github.com/libimobiledevice/libimobiledevice/blob/master/docs/idevicediagnostics.1).
